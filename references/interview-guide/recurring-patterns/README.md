# Recurring Patterns — 사후 추출 snippet 보관소

> **상태**: 빈 폴더로 시작 (v2.0, 2026-06-04)
> **목적**: 같은 인터뷰 답변 패턴이 **3회 이상** 반복됐을 때만, 그 패턴을 snippet 으로 등록해 SCOPER 가 다음 인터뷰에서 "예시" 로 제시할 수 있게 합니다.

---

## 1. 왜 빈 폴더로 시작하나

이게 본 skill 의 핵심 철학입니다:

| 잘못된 접근 (v1.x, v2.0-α) | 올바른 접근 (v2.0) |
|---|---|
| Skill 이 사전에 "이 도메인은 이렇게 분석한다" 를 정의 | Skill 은 인터뷰만 정의. 패턴은 사후에 발견 |
| 분류·메트릭·방법론을 미리 박제 | 사용자가 인터뷰에서 도출. 자주 반복되면 그제야 박제 |
| "광고는 EY backbone 이다" 같은 하드코딩 | 광고 인터뷰 3회 후 같은 backbone 이 도출되면 그때 snippet 등록 |

빈 폴더는 **"우리는 미리 정답을 알지 않는다"** 는 선언입니다.

---

## 2. 등록 기준 (Promotion Criteria)

snippet 을 `recurring-patterns/<pattern-name>.md` 로 등록할 때 반드시 다음 모두 만족:

- [ ] 같은 분류·메트릭·방법론 조합이 **3회 이상** 다른 사용자·다른 리서치에서 인터뷰 산출물로 도출됨
- [ ] 3회 모두 사용자가 동일 패턴에 명시 동의
- [ ] 패턴이 SaaS-편향 같은 가정을 내포하지 않음 (사용자에게 묻지 않고 적용해도 안전한가?)
- [ ] 사용 시점에 **"예시" 로만 제시** 한다는 원칙 준수 (강제 적용 금지)

---

## 3. snippet 구조 (등록 시)

```markdown
# Pattern: <pattern-name>

## 발견 이력 (3회 이상)
| Run ID | 사용자 | 일자 | 적용 결과 |
|---|---|---|---|
| ... | ... | ... | 본 패턴이 사용자 인터뷰 산출물에서 그대로 도출 |

## 패턴 요약
- **Phase A 답 패턴**: ...
- **Phase B 분류 패턴**: ...
- **Phase C 메트릭 패턴**: ...
- **Phase D 스타일 + 방법론 패턴**: ...
- **Phase E 산출물 패턴**: ...

## SCOPER 가 인터뷰 중 제시하는 발화 예시
"이전 N회의 비슷한 리서치에서 X 패턴이 도출됐습니다. 차용하시겠어요, 직접 정의하시겠어요?"

## 비고
- 이 패턴은 [도메인/문제유형] 에 자주 매칭됨
- 그러나 매칭이 안 되는 케이스도 있으므로 사용자 결정 우선
```

## 4. 첫 후보가 될 가능성 있는 패턴들

(아직 등록되지 않음. 단순 메모.)

| `policy-impact-baseline` | (미발생) | 3회 필요 |

## 5. 사후 추출 워크플로우 (어떻게 등록되는가)

```
[1] 새 리서치마다 SCOPER 인터뷰 산출물 (Research Brief) 가 learning-log/runs/<date>/scoper-output.md 에 저장됨
[2] 분기마다 (또는 5+ 리서치 누적 시) 운영자가 산출물 비교
[3] 같은 패턴이 3회 이상 발견되면:
   - recurring-patterns/<pattern-name>.md 에 등록
   - 본 README 의 "후보" 목록 업데이트
   - SCOPER 가 다음 인터뷰부터 "예시" 로 제시 가능
[4] 등록 후에도 강제 적용 금지. 사용자 결정 우선
```

## 6. 등록 거부 사유 예시

다음 중 하나라도 해당되면 **등록 거부**:

| 거부 사유 | 예시 |
|---|---|
| 한 사용자만 반복 | 한 명의 PM 이 같은 패턴 5회 → 개인 선호일 가능성. 다른 사용자 검증 필요 |
| 분야·도메인 가정 내포 | "이 패턴은 광고 시장에만 적용" → 도메인 어댑터의 재발 |
| 외부 표준 의존 | "EY 분류" 같은 외부 표준은 표준 자체로 보관 (우리가 owner 아님) |
| 사용자 인터뷰에서 도출되지 않고 SCOPER 가 제안한 패턴 | SCOPER 가 박제한 것은 우리의 가정. 사용자 도출이 아니므로 등록 불가 |
